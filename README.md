# Mariwala Super League (MSL)

Official MSL Cricket League Website and Mobile App.

## Project
- League: Mariwala Super League
- Season: 9 (2026)
- Ground: Jhabar Cricket Ground, Thamewali, Mianwali

## Features
- Live cricket scores and match updates
- Teams and player profiles
- Points table and statistics
- Previous seasons and champions
- Admin panel for league management
- Firebase-powered data synchronization
- Mobile-friendly design

More features and deployment configuration will be added during development.
